## 目标与边界

在现有 `co_breathing_visual` 中增加 Exhibition Mode，复用 TypeScript、Three.js、GLSL、鱼体关节约束、Boids 和流体渲染基础，不新增依赖或网络协议。

- 保留 1:1 正方形水域，宽屏居中留黑。
- 两种程序化鱼：带状鱼和扇鳍鱼；彩色细线、透明鳍膜、柔和发光。
- 展示鱼数 3–24，默认 4 条、两种形态各 2 条；单鱼工作台允许 1–2 条。
- 鱼的运动向原有 GPU 流体注入青色染料，形成连续的流动、卷曲和扩散；不绘制点状粒子。
- 人的运动同时影响水流和鱼；慢动温和、快动受惊、停留后逐渐恢复。
- 当前 Mac（Apple M3 Pro）与 Chrome 是桌面验收基线。

参考：[Aquatics 制作视频](https://vimeo.com/800086878)、[作者技术说明](https://philippartus.com/aquatics)。制作视频 00:07–00:31 说明以 joint chains 为构形基础、组合成鳍后再打磨游泳运动；官网说明把动画、物理、AI 的性能敏感部分转移到 GLSL／GPU。本项目借鉴构形思路，不移植作者代码或素材，也不声称复现其未公开的具体公式。最多 24 条鱼的行为与粗关节链继续在 CPU 上固定步长运行；曲面插值、微波动与纹理着色在 GPU 上计算。

本展示版是明确标识的程序生成视觉。它不是中国真实鱼群数据源，不改写 v4.0 真实鱼与跨国控制的定义。默认展示入口不初始化摄像头或硬件客户端；原调试入口仍独立用于联调。远端真实鱼驱动画面的映射另行设计。

## 六步执行与验收

### 1. 展示入口和单鱼工作台

- `/?view=exhibition`：完整展览画面。
- `/?view=exhibition&scene=specimen`：物种选择、单鱼／双鱼对照、骨架辅助线与固定运动片段。
- `/?view=exhibition&scene=flow`：向右／向上的恒定流场测试。
- 原 `/` 保持模拟调试、摄像头和硬件联调入口。
- 展示画面隐藏人物 ID、障碍圆、泵位、雾化状态及工程按钮，保留程序生成来源标识。
- D 操作面板，F 全屏，Space 暂停，R 重置；编辑输入时不触发全局快捷键。全屏包含黑边，保持正方形。

验收：1080p、720p、窗口缩放与全屏均无拉伸；展示入口没有摄像头或执行器网络请求；原调试入口可使用。

### 2. 两种鱼的形态和游动

展示主脊柱使用独立 `ExhibitionBody`：角度链前向构形保证每段长度不变，限制相邻弯曲；头部稳定、向后传播并增强的主波叠加小幅谐波，转向沿身体延迟。圆润肩部通过宽度函数收窄到尾柄。原调试模式继续使用原 FishBody。

鳍条从 5 点增加到 9 点，角度弹簧从根部到尖端降低刚度，产生连续弯曲、相位滞后与回弹。胸鳍与尾鳍使用不同频率，尖端叠加小幅波动；鳍根范围与鳍长曲线按物种区分，防止相邻鳍条在运动中局部交叉。水流影响鳍条偏转。主动推进量平滑后驱动摆尾，滑行时逐渐收敛，停留仍有轻微鳍动。

| 物种 | 主链 | 形态与运动 |
| --- | --- | --- |
| 带状鱼 | 18 节 | 细长、长尾、较柔软；身体后半段弯曲较明显，滑行较长 |
| 扇鳍鱼 | 14 节 | 短而饱满、胸鳍展开、扇形尾鳍；转向较灵活 |

全长约为水域边长 12%，固定种子生成 ±15% 个体尺度差异；改变鱼数不自动缩放个体。单鱼预览用摄影机放大，实际模拟尺寸不改变。

固定运动片段：直游、缓转、急转、加速、滑行、停留；循环时每段 6 秒。摆尾与主动游速对应，停留保留轻微鳍动。

同日修订：取消巡游方向中持续累积的正弦偏转及绕人的切向力；角速度受主动游速／最小转弯半径约束，半径为全长的 0.8 倍。减速时转向同步放缓，零推进时不旋转。展览巡游的减速阶段保留向前滑行，边界避让提前观察前方位置。

验收：黑白剪影可分辨物种；运动连续、约束稳定；身体和鳍完整留在水域中。

### 3. 着色和投影可读性

GPU 参数曲面替代逐帧在 CPU 上重画线段：每条鱼固定四块参数网格（身体、左右鳍、尾鳍），仅更新一张 32×28 浮点控制纹理，上传插值后的关节与鳍条。Vertex Shader 做 Catmull–Rom 曲线插值、身体展宽和边界内的小幅鳍膜波纹；网格和材质复用，纹理在销毁鱼时释放。

Fragment Shader 使用函数绘制随体纵向细丝、淡化横向骨纹、鳃弧、眼部高光、鳍条及末端分叉细纹。`fwidth` 抗锯齿与低于像素尺度的细纹衰减避免摩尔纹／白块；透明膜面与色偏表现褶皱，鳍尖从青色／蓝紫向更深的蓝色／紫色渐变。不依赖普通 WebGL 线宽，不增加可见粒子。

带状鱼青蓝、扇鳍鱼蓝紫、人为扰动低饱和琥珀色；头部略亮、尾端与鳍尖渐淡。警觉只短暂增强亮度。四分之一尺寸的分离模糊后合成柔光，指数色调映射限制叠加曝光。

面板提供曝光、线条亮度、柔光、鳍膜透明度、水中色彩和黑白检查；视觉参数可保存到当前浏览器。

验收：细线间隙清楚；鱼在尾流上可辨识；重叠时不长期成为白块；静帧与动态都能展示细节。

### 4. 恢复原流体效果并保留互动

展览与单鱼画面恢复调用原 `VisualFluid.step`：GPU 独立求解速度平流、涡量、压力和染料扩散／衰减。使用美化前的鱼体染料、人物／鼠标注入参数和青色／琥珀色流体色调，保留黑色背景与现有鱼体绘制。

CPU 64×64 场继续用于鱼的行为和鳍偏移，主动游泳与被水推动分开计算。正常展示不再将该场直接上传为视觉速度；`scene=flow` 作为独立方向测试保留外部速度场路径。两条路径切换时清除不同的纹理采样偏移。

每条鱼注入一处连续染料，按鱼数归一化发射强度；人物移动和最近鼠标采样注入暖色扰动。染料注入仍分批完整处理，超过 24 点也不截断人物输入。移除点状粒子的生成、更新和绘制，不只是降低粒子亮度。

| 画质 | 流体纹理 | DPR 上限 |
| --- | --- | --- |
| 标准 | 512×512 | 1.5 |
| 低负载 | 256×256 | 1 |

两档共用相同 CPU 行为网格，均不显示粒子。模拟坐标左上原点，染料注入时处理 Y 翻转。

验收：展示实际调用原 GPU 求解器、GPU 点绘制数量为零；方向测试场景染料方向正确；24 条鱼仍收到人物扰动；停止注入后能量与染料衰减。

### 5. 群游和人鱼关系

在局部视野内选最近最多 6 个邻居，计算分离、对齐、聚合；分离尺度与鱼体尺寸相关。物种有转向与滑行差异，允许混群，不加入捕食。

人速度以水域边长／秒计：0.08 以下温和，0.30 以上快速，中间连续过渡。近距离增加警觉；快动只影响局部鱼。警觉快速建立、按约 3 秒尺度衰减。

慢动时鱼绕行、偏转，部分低警觉个体在个人空间外围试探；快动时加速散开；停留后运动注入停止，鱼保持安全距离并逐步恢复；人物离开后警觉连续衰减。

固定输入片段：无人、慢速经过、快速横扫、中心停留、三人交错。外部匿名观众未来可通过现有 InteractionSource 形状接入；本轮展示入口不主动连接识别服务。

验收：4／12／24 条的聚合、分散与恢复可见；快慢反应有区别；不持续卡边、不穿入人物核心、不无限加速。

### 6. 性能、现场检查和交付

固定参数网格与控制纹理；60 Hz 物理步进、关节与相位渲染插值；暂停／恢复清除积压，后台不补算长时间物理；不自动降低鱼数或改变行为。

当前 Mac、Chrome、1920×1080、标准画质、24 条鱼与三人交错连续运行 30 分钟。预热后平均至少 55 FPS，95% 帧间隔不超过 25 ms。记录浏览器/GPU、图形资源、模拟时间、错误与桥接请求，保留实际结果。

桌面验收命令：`npm test`、`npm run build`、`npm run test:e2e`。
录屏／截图：`npm run test:media`。
长测：先 `npm run build`，再 `npm run test:benchmark`；长测使用 4174 端口的冻结构建，避免开发热更新。

交付物位于被 Git 忽略的 `outputs/exhibition/`：两种单鱼及双鱼图、4／12／24 鱼群截图、单鱼循环与群游 WebM 录屏、30 分钟结果 JSON。常规测试不自动执行长测或录屏。

真实投影仪尚未参与验收：需要现场检查黑位、鱼体尺寸、细线可见性、色彩重叠与余辉，并保存展示参数。不能将桌面测试等同于现场投影验收。

## 展示模块与操作基线

| 模块 | 职责 |
| --- | --- |
| `src/main.ts` / `src/debug-main.ts` | 按 URL 延迟加载展示或原调试入口，隔离硬件初始化 |
| `src/exhibition/config.ts` / `scenarios.ts` | 物种、画质、响应阈值、种子及可重复的输入／动作片段 |
| `src/exhibition/world.ts` / `fish.ts` | 固定步长世界、CPU 行为流场、群游、警觉、独立弹簧鳍条 |
| `src/exhibition/body.ts` | 展示专用的定长角度链、后向传播的身体波与宽度曲线 |
| `src/exhibition/fish-view.ts` / `fish-shaders.ts` | 固定参数网格、控制纹理上传、GPU 曲面插值、微波动、函数细纹和透明膜面 |
| `src/exhibition/renderer.ts` | 原 GPU 流体、独立方向测试路径、MSAA 与低分辨率柔光合成；不绘制粒子 |
| `src/exhibition/main.ts` / `style.css` | 展示面板、全屏、暂停、鼠标、参数保存与诊断／录屏接口 |

以上路径均相对于 `co_breathing_visual/`。共享模块仅扩展可选参数／路径，原调试入口不采用展示的统一速度求解器。

桌面默认视觉参数：曝光 `1.25`、线条 `1.00`、柔光 `0.45`、鳍膜 `0.10`、染料 `1.00`。它们是本轮审阅基线，不是已完成现场标定的投影参数。

操作恢复：R 重建鱼和流体，但保持当前暂停状态；Space 恢复游动。切换画质会重置模拟。暂停或后台恢复不会补算积压时间。图形上下文中断时暂停并提示，恢复后重新载入。视觉参数保存于当前浏览器，URL 用于复现鱼数、种子、画质和互动片段。

## 回归与复现

- 覆盖两种鱼的距离约束、完整鱼鳍边界、有限数和 3／4／12／24 条鱼运行。
- 鱼体修订额外检查：静止鳍梢持续变化、鳍条有实际曲率、关节定长、身体后部波幅大于前部、六段运动中的鳍条网格不局部翻折，以及渲染更新不重建参数网格／控制纹理。
- GPU 内容回读直接渲染两种鱼，检查可见且非全白、停留时鳍面变化、黑白模式无色差、关闭线条与膜面后没有残留。像素变化只用于功能回归，外观仍通过截图与录屏审阅。
- 覆盖流向与 Y 翻转、注入数量、停止后衰减、主动游泳和被动漂移的区别。
- 浏览器测试直接读取 GPU 纹理，检查方向测试中的染料位移、逐秒衰减、第 99 个注入点，以及恢复原 GPU 求解器后的结果一致性；另检查实际无点状粒子绘制。
- 固定种子和同一输入产生一致 CPU 状态；GPU 检查采用容差，不要求跨 GPU 像素相等。
- 覆盖固定互动、暂停、恢复、重置、全屏、面板隐藏和展示网络隔离。
- 保留原硬件安全与观众输入测试；异步入口测试等待模拟就绪再发送快捷键。
- 视觉验收依靠静帧和运动检查，不能用像素变化替代审美判断。
