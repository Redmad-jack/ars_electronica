# Co-Breathing v4.0 运维界面规范

P0 不建设新前端，只定义后续最小运维界面的信息边界。旧 TypeScript 可视化仅作映射研究工具，不是鱼群数据源，也不进入展览正式控制链。

2026-09-08 补充：用户已确认在现有可视化应用中增加独立的程序生成投影展示入口。其视觉与互动范围见 [EXHIBITION_VISUAL_PLAN.md](EXHIBITION_VISUAL_PLAN.md)。展示入口不初始化摄像头或执行器客户端，不作为中国真实鱼群数据源；原调试入口继续用于本地联调。本补充不改变以下运维界面规范。

## 1. 必须显示

- 当前站点、`SAFE_OFF` / `LIVE_REMOTE` / `DEGRADED_LOCAL`。
- `data_source=remote_fish` 或 `procedural_fallback`。
- 相机、视觉后端、MQTT、串口/执行器适配器和看门狗健康状态。
- 消息年龄、最近有效序列、数据质量和 `capacity_exceeded`。
- 16 路震动或 3–9 路泵的目标值与实际适配器模式（`noop`/真实）。
- 安全事件和本地急停状态。

## 2. 操作边界

- 真实输出默认关闭；从 `noop` 切换真实驱动必须是本地明确操作。
- 急停可随时执行；清除急停与恢复运行必须分开。
- 雾化只提供本地定时命令，显示剩余时间；不提供跨国自动开关。
- 不提供人脸、视频远传、身份信息或逐通道公网控制。

## 3. 视觉语言

- 正常远端使用中性色；程序退流使用清晰但不惊扰观众的琥珀色；安全关闭使用红色。
- 状态文字不可只靠颜色区分。
- 延迟、质量和输出值使用原始可审计单位，避免用含糊的“智能程度”。
